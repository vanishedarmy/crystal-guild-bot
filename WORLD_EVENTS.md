# Crystal Guild v1.9.0 Alpha 6 — World Events Catalog

World Events are spontaneous stream-only Notorious Monster encounters. They use the normal Active Battle system, open a **90-second rally**, and never create a Raid. Event level is based on the Guild's highest current character level with a hard ceiling of **highest +10**.

## Stream timing
- First eligible roll after **15 minutes** of live-stream grace time.
- Subsequent eligible checks every **8–12 minutes**.
- Each eligible check has a **25%** World Event spawn chance.
- After an event resolves or passes unanswered, the next World Event is held for **30–45 minutes**.
- Only one Guild-wide encounter can be active at once.

## Reward posture
Each variant applies enhanced HP/power and a controlled reward multiplier to its familiar base monster. The intent is **better than an ordinary encounter, below Raid-scale rewards**, so World Events are exciting without becoming mandatory farming content.
