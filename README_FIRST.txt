Crystal Guild v1.9.0 Alpha 8 — Seasonal Event Framework
Runtime/frontend: 1.9.0-seasonal-events-alpha8
Schema 21 | Hosted sync 1 | Portal Action protocol 37

Alpha 8 adds the reusable Seasonal Event Framework and its first content pack, Night of the Hollow Crystal. The Halloween edition installs disabled by default, layers seasonal monsters and the Hollow Warden onto existing combat, adds Moonlit Tokens, rotating objectives, the Moonlit Emporium, and four permanent event trophies. Existing schema 20 databases migrate automatically to schema 21 with a verified pre-migration backup. No player reset is required.
