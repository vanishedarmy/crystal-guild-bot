# Crystal Guild v1.8.0 Alpha 2 — Merc Service Balance & UX

Alpha 2 is a stabilization and readability pass on the Hero Merc Service.

## Changes
- Reworked Current Contracts into a visual Hunt / Venture / Raid deployment board.
- Added exact mission-specific availability reasons to every Hero state.
- Filled mission slots can now be inspected directly without the UI forcing selection to another open job.
- Rebalanced Hunt Seal fees to Aerith 5, Tifa 6, Zidane 5, Yuna 7, Balthier 9, Cloud 12.
- Kept all Hero signature combat effects unchanged after value review.
- Kept the existing three independent contract slots, Hunt Seal economy, and mission-scoped consumption rules.
