# Crystal Guild v1.3.0 — Guild Expansion Beta 1

Guild Expansion Beta 1 is the economy and progression balance checkpoint for the v1.3 Fellowship/Airship release.

Runtime `1.3.0-guild-expansion-b1` · local DB schema **9** · hosted sync schema **1** · Portal Action protocol **21** · Twitch prefix `!`.

Beta 1 preserves Guild Facilities, Guild Projects II, Workshop services, Weekly Order participation rewards, the persistent Guild Airship, Guild Legacy, and the Founding Hall visual pass. The balance changes are limited to Airship Dock construction, the Crystal Guild Airship launch project, and Airship upgrade requirements.

Use `tools/simulate_guild_balance.py` to reproduce the fixed-seed Guild economy simulation. See `reports/GUILD_BALANCE_SIMULATION.md` for the shipping 3,000-season report.
