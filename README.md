# Crystal Guild v1.1.16 — Arsenal Hotfix 6

Arsenal expands every Job to six active Battle Abilities and adds lower-level Hunts, world bosses, and crafting content. Hotfix 6 tightens Daily Guild Provisions so only explicitly approved ordinary consumables and crafting materials can roll; Chocobo Registration Writs and other special/progression items are excluded. Orphaned Writs created by the old Daily pool are repaired automatically when Chocobo state is checked, while legitimate purchased Writs remain intact.
