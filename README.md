# Crystal Guild v1.7.0 — Retainer Service Alpha 2

Current Alpha baseline: `1.7.0-retainer-a2` · DB schema 15 · Portal Action protocol 31 · Twitch prefix `!`.

The Retainer Service provides timed, Gil-funded crafting-material procurement with one personal Retainer and one assignment at a time. Rewards are fixed at dispatch, persist through restarts, and are granted exactly once on collection. The v1.6.0 Gold Saucer production systems remain intact.
